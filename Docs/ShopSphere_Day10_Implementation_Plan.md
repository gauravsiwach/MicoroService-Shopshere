# ShopSphere Day 10 – Phase-wise Implementation Plan

## Phase 0 Review Existing Platform
Verify Day 8 services.

## Phase 1 Test Environment
Create application-test.properties, dedicated datasource and @ActiveProfiles("test").

## Phase 2 JUnit 5
Lifecycle, assertions, parameterized, exception, positive & negative tests.

## Phase 3 Mockito
@Mock, @InjectMocks, repository mocking, stubbing and interaction verification.

## Phase 4 Spring Boot Test
@SpringBootTest, context loading, service and controller testing.

## Phase 5 TestRestTemplate
GET, POST, PUT, DELETE validation.

## Phase 6 Rest Assured
API validation, headers, JSON, path/query params, positive & negative tests.

## Phase 7 Java HTTP Client
Synchronous and asynchronous request tests.

## Phase 8 Security Testing
JWT, RBAC, Authority tests (ORDER_CREATE, ORDER_UPDATE, ORDER_DELETE, INVENTORY_UPDATE, NOTIFICATION_SEND), 401/403, public/protected APIs.

## Phase 9 Final Validation
Verify unit, integration, API and security tests execute using the test profile.
